# 🏡 Real Estate Website

A modern, responsive real estate website designed to showcase residential properties, highlight home interiors, and provide visitors with an elegant browsing experience.

The website features property galleries, neighborhood information, house layouts, and a contact form for potential clients.

## ✨ Features

- **Modern Landing Page:** Attractive hero section with a clear call to action.
- **About Section:** Introduction to the real estate company.
- **Property Gallery:** Showcase of featured residential properties.
- **Interior Showcase:** Dedicated sections for kitchens and living rooms.
- **Neighborhood Highlights:** Information about the surrounding environment and facilities.
- **Floor Plan Section:** Visual presentation of house layouts.
- **Contact Form:** Interactive form with basic input validation and submission feedback.
- **Back to Top Button:** Quick navigation to the top of the page.
- **Responsive Design:** Layout adapts to desktop, tablet, and mobile screens.
- **Smooth Navigation:** Navigation links with smooth scrolling.

## 🛠️ Technologies Used
